## Market Lessons

The winners tend to do at least one of these well:

- own a category in one sentence;
- show installation in the first screen;
- give the user a runnable or invocable artifact immediately;
- use public maintainer language, not "prompt dump" language;
- organize by actual workflow, not by a pile of clever ideas;
- make contribution rules clear enough that quality can survive attention.

The weak spots are also consistent:

- catalogs are useful but interchangeable;
- broad packs require constant maintenance;
- "autonomous" claims invite skepticism unless proof artifacts exist;
- aggressive performance claims age badly without measurements;
- skill repos often explain the format but not the operating discipline.

## The Opening

Fastlane should not compete as "more skills." It should compete as the missing
execution protocol for agent delegation:

1. The parent agent owns architecture and acceptance.
2. The worker owns bounded construction.
3. Proof must be causal, not just green.
4. TempoFastlane measures the wall clock and corrects duration intuition.

That wedge is narrow enough to be credible and broad enough to matter across
real Codex work.

## Category Claim

Recommended category:

> Delegation control protocol for Codex.

Alternative category phrases:

- Model-routed delegation protocol
- Proof-gated worker delegation
- Temporal calibration for coding agents
- Parent-gated implementation lane

Avoid:

- "prompt library"
- "AI automation framework"
- "fully autonomous coding"
- "production-ready" without proof
