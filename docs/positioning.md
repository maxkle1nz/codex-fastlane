# Positioning

## Product Thesis

Fastlane is the parent-gated delegation protocol for Codex.

TempoFastlane is the flagship: Fastlane plus TEMPONIZER, a phase-aware
calibration loop that corrects agent duration estimates using measured
wall-clock execution time.

## One-Liner

Delegate Codex work at lane speed. Accept it at proof speed.

## Short Description

Fastlane and TempoFastlane turn worker models into bounded implementers while
the parent agent preserves premium reasoning for architecture, synthesis,
integration, and final verification.

## GitHub About

## Audience

Primary:

- Codex power users who already delegate work to agents;
- maintainers who want faster implementation without accepting weak proof;
- teams building repeatable agent workflows.

Secondary:

- people maintaining skill libraries;
- AI coding tool researchers;
- engineering managers testing agent orchestration patterns.

## Narrative Pillars

1. Speed is allowed only when scope is bounded.
2. Parent judgment stays centralized.
3. Proof must identify the new path, not merely show a passing command.
4. Time estimates from language models are inherited priors, not measurements.
5. TempoFastlane improves by measuring `Te` and recalibrating future choices.
6. Frontier parent models should manage lanes before they write routine code.

## The Wedge

Most repos teach agents what to know. Fastlane teaches agents how to delegate.

That distinction matters because the failure mode of modern coding agents is
less "cannot write code" and more "accepts the wrong evidence too early."

## Voice

Use:

- concrete engineering nouns: worker, parent, proof, artifact, baseline,
  ownership, phase, wall clock;
- direct maintainer verbs: verify, constrain, measure, integrate, harden,
  accept, reject;
- confidence that comes from limits;
- visual symbols when they map to the system: 🏁 lanes, ⚡ Spark, 🧪 proof,
  🛑 parent gates, 🧭 judgment, and 🕒 temporal calibration.

Avoid:

- "magic";
- "autonomous developer";
- "10x";
- "production-ready";
- "never fails";
- decorative emoji that does not map to the protocol.

## Public Claim Discipline

Safe claims:

- "proof-gated";
- "bounded delegation";
- "parent-side verification";
- "phase-aware temporal calibration";
- "measures execution time when feasible."

Claims that require evidence before use:

- "faster than X";
- "best";
- "leader";
- "production-ready";
- "enterprise-grade";
- "eliminates all false positives."

## Naming

Recommended repository slug:

```text
codex-fastlane
```

Reason: `fastlane` alone is crowded and already associated with mobile release
automation. `codex-fastlane` keeps search intent while making the category
obvious.

Recommended hero:

```text
Fastlane for Codex
```

Recommended flagship label:

```text
TempoFastlane
```

Reason: the base brand is easy to remember; the flagship owns the unique
TEMPONIZER angle.
